## Two things are on by default in this release

- **Usage telemetry.** Once a day Yardhand sends one anonymous report: ranges and yes/no answers about how it is set up and used, with no names, addresses, queries or keys. The first goes 24 hours after this version first starts, and Settings shows the exact report before then. `GATEWAY_TELEMETRY=off` (or `DO_NOT_TRACK=1`) in `.env` switches it off. [docs/telemetry.md](https://github.com/escalay/yardhand/blob/main/docs/telemetry.md) lists every field.
- **An updater container in the compose file.** It installs an update when you choose "Update now" in Settings, and puts the old version and your data back if the new one doesn't come up. To do that it holds the Docker socket, which is as good as root on the machine; the gateway itself still has no such access. `GATEWAY_UPDATER=0` in `.env` removes it, and `GATEWAY_UPDATE_CHECK=off` stops the daily check for a newer version. Nothing updates by itself unless you switch that on. [docs/updates.md](https://github.com/escalay/yardhand/blob/main/docs/updates.md) explains every step.

**Coming from 0.2.0 or earlier,** this update is by hand, since those versions have no updater:

```sh
curl -fsSL -o docker-compose.yml https://github.com/escalay/yardhand/releases/latest/download/docker-compose.yml
docker compose pull && docker compose up -d
```

From then on, Settings does it.
