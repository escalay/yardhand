## Search now returns only what clearly matches

- **A search that matches nothing returns nothing.** `search_tools` and `GET /api/tools?q=` return only tools that clearly match the question. Before, they returned the nearest tools every time; now an off-topic question answers `count: 0`.
- **What it costs, measured.** Replayed on one instance's log of agent searches (57 where the agent went on to call a tool; 53 of those tools can still be returned): the tool the agent then called was still returned in 51 of 53 (before: 53 of 53) and was first in 26 (before: 26). Four gibberish queries returned 20 tools each before and none after. An off-topic query in a 24-tool pack went from about 9 results to under 1.
- **Small gateways search as before.** A gateway with fewer than 50 tools, or without search by meaning, is unchanged.
- **A pack key sees its pack's own counts.** `list_upstreams` and `GET /api/upstreams` count only the tools, playbooks and manuals the pack holds, and `GET /api/links` is empty for a pack key.

Nothing to do by hand: no new setting, no data change.
